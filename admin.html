⚙️ Configuração necessária — Cloud Function

Para listar utilizadores do Firebase Auth é necessária uma Cloud Function (o Firestore não dá acesso directo à lista de Auth por segurança). Segue os passos abaixo uma única vez:

1
Instala o Firebase CLI e inicializa as functions no teu projecto:
npm install -g firebase-tools firebase login firebase init functions # escolhe JavaScript, sem ESLint
2
Substitui o conteúdo de functions/index.js por:
const {onRequest} = require("firebase-functions/v2/https"); const admin = require("firebase-admin"); admin.initializeApp(); // ← SUBSTITUI pelo teu email de admin const ADMIN_EMAIL = "TEU_EMAIL_AQUI@gmail.com"; exports.adminGetUsers = onRequest({cors: true}, async (req, res) => { // Verify caller is the admin (via ID token) const auth = req.headers.authorization?.split("Bearer ")[1]; if (!auth) return res.status(401).json({error:"Sem token"}); try { const decoded = await admin.auth().verifyIdToken(auth); if (decoded.email !== ADMIN_EMAIL) return res.status(403).json({error:"Acesso negado"}); const result = await admin.auth().listUsers(1000); const users = result.users.map(u => ({ uid: u.uid, email: u.email || "—", displayName: u.displayName || "", createdAt: u.metadata.creationTime, lastLogin: u.metadata.lastSignInTime, disabled: u.disabled, })); res.json({users, total: users.length}); } catch(e) { res.status(500).json({error: e.message}); } });
3
Faz deploy da função e copia o URL:
firebase deploy --only functions # URL gerado: https://admingetusers-XXXXX-uc.a.run.app
4
Cola o URL no campo CLOUD_FUNCTION_URL no topo deste ficheiro admin.html (linha ~10 do script).
